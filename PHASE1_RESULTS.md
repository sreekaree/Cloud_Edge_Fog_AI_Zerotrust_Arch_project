# MedTrustEdge Phase 1 Results

## Scope

Phase 1 establishes a reproducible Cloud–Fog–Edge networking baseline only. It includes no AI, blockchain, Zero Trust, trust scoring, authentication, authorization, anomaly detection, or orchestration functionality.

## Topology

The Phase 1B experiment ran six synthetic IoMT hosts (`iotA1`–`iotA3`, `iotB1`–`iotB3`), two Edge routers, two Fog routers, and one Cloud host: 11 hosts total. Eight logical OVS switches define tenant access, Edge–Fog, Fog–Cloud, and direct-baseline segments. They retain deterministic DPIDs and use short Linux-safe Mininet aliases. OVS bridges run in standalone mode so their normal MAC-learning forwarding works without an OpenFlow controller.

Tenant A uses `10.1.x.x` primary segments and Tenant B uses `10.2.x.x`; cloud-only baseline interfaces use `10.10.1.10` and `10.10.2.10`. All traffic is synthetic.

## Methodology

The real Mininet/OVS run sent five ICMP echo requests from each of the six IoMT hosts for each scenario. The CSV `mean_rtt_ms` field is the per-host ping-reported average RTT. Aggregate mean/min/max values below summarize those six per-host averages. Raw `ping` output, including each host's RTT min/avg/max/mdev and packet counts, is preserved in every CSV row.

| Scenario | Path | CSV |
|---|---|---|
| Edge latency | IoMT → tenant Edge | `results/mininet/mininet_edge_latency.csv` |
| Fog latency | IoMT → Edge → tenant Fog | `results/mininet/mininet_fog_latency.csv` |
| End-to-end | IoMT → Edge → Fog → Cloud | `results/mininet/mininet_end_to_end_latency.csv` |
| Cloud baseline | IoMT → Cloud baseline interface | `results/mininet/mininet_cloud_baseline.csv` |

## Result Integrity and Plots

`results/mininet/` contains exactly the four real-measurement CSV files above. Their sources are the six IoMT hosts and their destinations match the intended tenant Edge, Fog, routed Cloud, and baseline Cloud addresses. No fallback CSV is present in that directory.

The existing `plots/` PNGs were generated by Phase 1A from `results/fallback/`; they are not Mininet plots and are not used to summarize the table above. The Phase 1B runner currently writes raw CSV measurements only.

## Reproducibility

```bash
sudo mn -c
sudo python3 experiments/run_mininet_phase1b.py
```

Then run the unit suite from the repository root:

```bash
python3 -m unittest discover -s tests -v
```

## Limitations

The traffic is synthetic ICMP latency/loss measurement rather than clinical data or application-layer healthcare protocols. No throughput measurement or Mininet-specific plot is generated by the current runner. Phase 1 remains a baseline; it does not establish future research-performance or security claims.
